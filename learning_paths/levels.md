
# Why Your Machine Learning Projects Won't Land You a Job (The 5 Levels of ML Projects)

![Thumbnail](https://i.ytimg.com/vi/Bx4BYXOE9SQ/maxresdefault.jpg)

[![Watch the video](https://img.youtube.com/vi/Bx4BYXOE9SQ/0.jpg)](https://www.youtube.com/watch?v=Bx4BYXOE9SQ)

The video outlines five levels of machine learning (ML) projects, detailing the progression from entry-level tasks to advanced ML systems, and what skills are necessary at each stage to secure a job in the field. It emphasizes the importance of proper project types for different roles and highlights common pitfalls for aspiring ML engineers.

## Key Points

### Level 1 Projects

Beginner projects mainly involve clean, structured datasets in a Jupyter notebook environment. Practitioners typically use libraries such as Pandas for data manipulation and sklearn for training basic models like linear regression. This level focuses on exploratory analysis, model training with default parameters, and evaluation using basic metrics, illustrating the difference between academic projects and real-world applications.

### Level 2 Projects

At this stage, individuals work with messier, real-world data. Projects are structured akin to a professional workflow, utilizing version control with Git, train-validation-test splits, and advanced techniques for handling class imbalance. Typical projects evolve to include customer churn predictions, showcasing a deeper understanding of data handling and model evaluation.

### Level 3 Projects

This level transitions from data science to machine learning engineering, emphasizing production readiness and scalability. Projects incorporate containerization with Docker, API development, and more sophisticated monitoring. An example is a content recommendation engine that operates in real-time, indicating readiness for industry challenges.

### Level 4 Projects

Focusing on robust and scalable solutions, level four projects involve advanced infrastructure tools like AWS or Google Cloud, alongside deep learning frameworks. Projects at this level tackle industrial-scale challenges, such as real-time fraud detection systems that implement complex monitoring and are designed for compliance and efficiency.

### Level 5 Projects

The pinnacle of ML projects, level five involves groundbreaking research and innovation. Here, practitioners invent new methods, such as designing custom neural architectures or pioneering hybrid models. These projects may not serve immediate production needs but push theoretical boundaries of AI, like creating scientific discovery systems.
